# DB Design — Stock Monitor
  用户权限（2张）
  - users — 登录、JWT 登出
  - user_access — 白名单/黑名单，user_id → users.id
                                                                                                                                                              
  行情数据（9张，jobs 写入）                                                                                                                                  
  - trade_dates — 交易日历                                                                                                                                    
  - limit_up_daily — 涨停板每日统计 + 赚钱效应（B1/B3 复用同一接口）                                                                                          
  - limit_up_leaders — 涨停龙头 + 净流入（B2/B10 复用同一接口）                                                                                               
  - limit_up_ambush — 涨停伏击三分类（B4）                                                                                                                    
  - limit_up_reasons — 个股涨停原因（B5）                                                                                                                     
  - stock_limit_stats — 个股历史统计指标（B6）                                                                                                                
  - sector_limit_stats — 板块情绪聚合（B7）                                                                                                                   
  - futures_realtime — 期货实时报价（B8）                                                                                                                     
  - futures_sector_links — 期货关联板块（B9）                                                                                                                 
                                                                                                                                                              
  龙虎榜（5张，jobs 写入）                                                                                                                                    
  - billboard_daily / hot_money / institution / broker / changes（B18）                                                                                       
                                                                                                                                                              
  告警系统（2张）                                                                                                                                           
  - alert_rules — 规则（backend 写，jobs 读）                                                                                                                 
  - alert_records — 触发记录，rule_id → alert_rules.id                                                                                                      
                                                                                                                                                              
  盘中监控（1张）                                                                                                                                             
  - monitor_list — user_id → users.id
                                                                                                                                                              
  回测（2张）                                                                                                                                               
  - backtest_results — user_id → users.id
  - backtest_trades — backtest_id → backtest_results.id

## 设计原则

- 行情数据表由 `jobs/` 写入，`backend/` 只读
- 所有行情表以 `(trade_date, secucode)` 作为唯一约束，支持 upsert 重跑
- 关联字段统一引用目标表主键 `id`
- 时间字段统一使用 `TIMESTAMPTZ`，日期字段使用 `DATE`

## 版本控制（Alembic）

- 迁移文件统一放 `backend/alembic/versions/`
- 每张新表或字段变更必须生成一个迁移文件，禁止直接手动改库
- 迁移文件一旦提交禁止修改，变更必须新建迁移文件
- 命名规范：`alembic revision --autogenerate -m "add_limit_up_daily_table"`
