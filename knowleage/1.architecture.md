# Architecture — Stock Monitor

## 项目概述

**Stock Monitor** 是一个 Web 端股票监控工具。

| 图片 | 功能模块 | 功能描述 | 难度 |
|------|----------|----------|------|
| img_1 | **涨停伏击列表** | 三分类 Tab（优质基因/冲刺/常客）；股票列表（名称+代码、价格、涨幅、行业） | 1 |
| img_5 | **期货品种弹窗** | 弹窗网格布局；每个品种显示名称 + 涨跌幅；当前选中高亮 | 1 |
| img_4 | **期货联动** | 期货品种下拉选择；关联概念板块涨幅标签；个股列表（净流入、价格、涨幅） | 2 |
| img_0 | **涨停总览页** | 顶部多 Tab 切换；赚钱效应评分 + 建议仓位；今日统计数字；龙头卡片横向滚动；底部监控分类 Tab | 3 |
| img_3 | **板块涨停详情** | 板块情绪统计栏（涨停家数/连板家数/龙头高度）；个股卡片同 img_2 结构 | 3 |
| img_2 | **个股涨停详情** | 概念筛选 Tag 行；个股卡片（涨停时间、价格、涨幅、涨停原因）；历史统计指标（封板率/连板率/次日红盘率等） | 4 |


### 后端功能

| # | 功能 | 说明 |
|---|------|------|
| B1 | 涨停板每日数据 | 家数、封板率、涨跌幅统计 |
| B2 | 涨停龙头数据 | 涨停天数、涨幅、所属概念 |
| B3 | 赚钱效应评分 | 封板率 → 强弱判断 + 建议仓位 |
| B4 | 涨停伏击分类数据 | 优质基因 / 冲刺 / 常客 三类 |
| B5 | 个股涨停原因文本 | 每只涨停股的原因说明 |
| B6 | 个股历史统计指标 | 封板率、连板率、次日红盘率等 |
| B7 | 板块情绪聚合数据 | 每个概念板块的涨停家数、连板家数、龙头高度 |
| B8 | 期货品种实时价格 | 各主力合约涨跌幅 |
| B9 | 期货关联板块映射 | 期货品种 → 关联 A 股概念板块 |
| B10 | 个股净流入数据 | 每只股票的资金净流入金额 |
| B11 | 用户认证 | 登录/登出，JWT token 签发与校验 |
| B12 | 白名单/黑名单控制 | 白名单用户才可访问，黑名单直接拒绝 |
| B13 | 告警规则存储 | 保存用户设置的股票 + 指标 + 阈值规则 |
| B14 | 告警检测任务 | 定时轮询，检查价格突破/涨跌幅/MACD 金叉死叉是否触发 |
| B15 | MACD 计算 | 根据历史 K 线实时计算 MACD 值，判断金叉/死叉 |
| B16 | 邮件推送（SMTP） | 告警触发后发送邮件通知 |

## 消息推送功能规则

**支持指标：**
- 价格突破：高于 / 低于设定价格
- 涨跌幅阈值：当日涨跌幅超过设定百分比（如 +5% / -3%）
- MACD 金叉 / 死叉：DIF 与 DEA 交叉时触发

**规则约束：**
- 同一股票最多设置 10 条告警规则
- 告警触发后自动变为「已触发」状态，不自动重置，需手动重启

**推送方式：**
- 邮件（SMTP，必选）
