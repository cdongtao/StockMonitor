# Coding Rules — Stock Monitor

## 禁止事项（AI 必须遵守）

### 安全
- ❌ 禁止将 Tushare Token / API Key / Secret Key 写入代码，必须从环境变量读取
- ❌ 禁止在前端硬编码 API URL，必须用 `VITE_API_BASE_URL` 环境变量
- ❌ 禁止跳过 Pydantic 验证直接操作数据库

### 数据库
- ❌ 禁止修改已提交的数据库迁移文件（`backend/alembic/versions/`），变更必须新建迁移文件
- ❌ 禁止在 `backend/` 代码中写入行情数据表，行情表只有 `jobs/` 可以写
- ❌ 禁止在 `jobs/` 代码中写入用户表、告警规则表，这两张表只有 `backend/` 可以写

### 前端
- ❌ 禁止在 `components/` 目录写业务逻辑，业务逻辑必须放 `hooks/` 或 `services/`
- ❌ 禁止在 React 组件中直接调用 fetch / axios，必须通过 `api/` 层
- ❌ 禁止使用 `any` 类型（TypeScript strict 模式）

## AI 实现规范（防止偷懒）

### 必须完整实现并通过测试
- ✅ 每个函数实现后必须有对应测试用例，测试通过才视为完成，不得以"先写逻辑后补测试"为由跳过
- ✅ jobs sync 任务：测试必须覆盖正常写入 + API 返回空数据两种场景
- ✅ backend 接口：测试必须覆盖正常响应 + 未登录 401 + 无数据 200 空列表三种场景
- ✅ 错误处理必须具体，禁止裸 `except Exception: pass` 吞掉异常
- ✅ 每个 API 接口必须有对应的 Pydantic Schema，禁止直接返回 `dict`
- ✅ 数据库操作必须在 `async with session` 上下文中，禁止裸调用 session 后不关闭

### 数据同步任务（jobs/）
- ✅ 每个 sync 任务必须实现 upsert（`ON CONFLICT DO UPDATE`），不得用先删后插
- ✅ 每个 sync 任务必须记录同步结果日志（成功条数 / 失败原因）
- ✅ 外部 API 调用必须设置 timeout（httpx 默认 30s），禁止无超时请求
- ✅ 单个任务失败不得中断整个同步流程，必须捕获异常后继续执行下一个任务

### 接口实现（backend/）
- ✅ 所有需要登录的接口必须注入 `Depends(get_current_user)`，不得遗漏
- ✅ 分页接口必须支持 `page` / `page_size` 参数，禁止一次返回全量数据
- ✅ 查询接口必须传入 `trade_date` 参数，禁止默认返回所有日期数据

### 前端实现（frontend/）
- ✅ 所有数据请求必须处理 loading / error 状态，禁止只写成功态
- ✅ 表格/列表组件必须支持空数据状态展示，禁止空数组时渲染空白页面
- ✅ 所有金额字段必须格式化（万/亿单位），禁止直接展示原始数字

## Mock 数据同步规范

- ✅ 每次修改 backend API 接口或 Schema 后，必须同步更新 `8.backend-mock-data.md`
- ✅ 每次修改 frontend 页面数据结构或请求字段后，必须同步更新 `9.frontend-mock-data.md`
- ✅ mock 数据字段必须与实际 Schema 完全一致，不得用占位值（如 `"xxx"`、全填 `0`）

## 命名规范

### Python（backend / jobs）
- 文件/模块：`snake_case`
- 类：`PascalCase`
- 函数/变量：`snake_case`
- 常量：`UPPER_SNAKE_CASE`
- 私有方法：`_leading_underscore`

### TypeScript（frontend）
- 文件/组件：`PascalCase.tsx`
- Hook：`useCamelCase.ts`
- 工具函数/变量：`camelCase`
- 类型/Interface：`PascalCase`
- 常量：`UPPER_SNAKE_CASE`

## 文件与目录规范

- 新增文件前先确认放在正确目录（参考 `2.backend-design.md` / `3.frontend-design.md` / `4.job-design.md` 目录结构）
- 修改或新增 `knowleage/` 文件后，检查其他文件是否需要同步（参考 `CLAUDE.md` 文档维护规则）
- 文件或目录改名后，必须用 `grep -rn` 扫描整个项目更新所有引用
