# Backend Design — Stock Monitor

## 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 框架 | Python FastAPI | ^0.110.x |
| 语言 | Python | ^3.11 |
| 异步 | asyncio + httpx | — |
| 数据验证 | Pydantic v2 | ^2.x |
| 数据库 ORM | SQLAlchemy (async) | ^2.x |
| 数据库 | PostgreSQL | ^16.x |
| 缓存 | Redis | ^7.x |
| WebSocket | FastAPI WebSocket | — |
| 任务队列 | APScheduler | ^3.x |

---

## 行情数据源（按优先级）

1. **Tushare Pro** — A 股主力数据源（需 token）
2. **Yahoo Finance (yfinance)** — 美股 / 港股备用
3. **Alpha Vantage** — 备用 API，有频率限制

---

## 目录结构

```
backend/
└── app/
    ├── main.py
    ├── core/
    │   ├── config.py      # 环境配置（pydantic Settings）
    │   ├── database.py    # 数据库连接（async SQLAlchemy）
    │   └── redis.py
    ├── api/
    │   ├── v1/
    │   │   ├── market.py
    │   │   ├── watchlist.py
    │   │   ├── portfolio.py
    │   │   └── alerts.py
    │   └── websocket.py
    ├── services/
    │   ├── market_service.py
    │   ├── alert_service.py
    │   └── portfolio_service.py
    ├── data_sources/      # 数据源适配器（统一接口）
    │   ├── base.py        # 抽象基类
    │   ├── tushare.py
    │   └── yfinance.py
    ├── models/            # SQLAlchemy ORM 模型
    │   ├── watchlist.py
    │   ├── portfolio.py
    │   └── alert.py
    ├── schemas/           # Pydantic 请求/响应 Schema
    │   ├── market.py
    │   ├── portfolio.py
    │   └── alert.py
    └── tasks/             # 定时任务（APScheduler）
        ├── price_polling.py
        └── alert_checker.py
```
