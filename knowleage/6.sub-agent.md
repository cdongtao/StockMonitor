## 项目概述

**Stock Monitor** 是一个 Web 端股票监控工具，核心功能包括：
- 实时行情展示与 K 线图
- 自选股管理与价格告警
- 组合持仓记录与盈亏统计

| 构建工具 | Vite | ^5.x |

### 后端
| 层级 | 技术 | 版本要求 |

| 框架 | Python FastAPI | ^0.110.x |

3. **Alpha Vantage** — 备用 API，有频率限制

## Sub-agents 分工（Claude Code）

当任务复杂时，按以下分工启动子 agent：

| Agent | 职责范围 | 禁止触碰 |
|-------|----------|----------|
| `data-agent` | 数据源对接、Redis 缓存、定时任务 | 不写任何前端代码 |
| `chart-agent` | K 线图、指标图表、图表交互 | 不写 API 和状态管理 |
| `alert-agent` | 告警规则逻辑、告警推送、通知 UI | 不改行情数据逻辑 |
| `portfolio-agent` | 持仓计算、盈亏统计、交易记录 | 不改告警和行情模块 |

## 开发流程约定

1. **新功能开发**：先在 `types/` 定义 TypeScript 类型 → 写 Pydantic Schema → 写 API → 写 Hook → 写组件
2. **数据库变更**：必须通过 Alembic 生成迁移文件，禁止直接修改表结构
3. **新增数据源**：继承 `BaseDataSource` 抽象类，实现统一接口，不允许绕过
4. **测试要求**：Service 层和工具函数必须有单元测试，API 路由必须有集成测试
