```
行情数据源（Tushare / yfinance）
    ↓ 定时拉取（APScheduler）
Redis 缓存（实时报价，TTL=5s）
    ↓
FastAPI 服务层
    ├── REST API → React Query（持仓、自选股等非实时数据）
    └── WebSocket → Zustand store（实时报价推送）
                        ↓
                  React 组件渲染
```

**缓存策略：**
- 实时报价：Redis，TTL = 5 秒
- K 线历史：Redis，TTL = 1 分钟（日线）/ 30 秒（分钟线）
- 持仓/自选股：PostgreSQL，前端 React Query staleTime = 30 秒

## 关键业务规则

### 价格告警
- 支持条件：价格高于 / 低于目标价、涨跌幅超过阈值
- 同一 symbol 最多设置 10 条告警规则
- 告警触发后自动变为「已触发」状态，不自动重置
- 推送方式：前端弹窗通知（必选）+ Webhook（可选）

### 持仓计算
- 盈亏 = (当前价 - 持仓均价) × 持仓数量
- 持仓均价采用加权平均法（分批买入时自动计算）
- 数量单位：A 股以「手」(100 股) 为最小单位，美股以「股」为单位
- 货币：A 股 CNY，美股 USD，混合持仓分组展示

### 数据刷新频率
- 交易时段（A 股 9:30-15:00 / 美股盘中）：WebSocket 实时推送，最快 3 秒/次
- 非交易时段：停止推送，显示最后收盘价
- K 线：按需请求，前端缓存 5 分钟
