# Frontend Design — Stock Monitor

## 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 框架 | React | ^18.x |
| 语言 | TypeScript | ^5.x（strict 模式） |
| 样式 | TailwindCSS | ^3.x |
| 图表（市场风向/柱状图） | Recharts | ^2.x |
| 图表（回测K线+买卖点） | TradingView Lightweight Charts | ^4.x |
| 图表（自选股mini分时图） | SVG 自定义（最后阶段，Yahoo Finance数据） | — |
| 状态管理 | Zustand | ^4.x |
| 数据请求 | TanStack Query (React Query) | ^5.x |
| 路由 | React Router | ^6.x |
| 构建工具 | Vite | ^5.x |

---

## 主导航结构

```
主 Tab（5个）：涨停精选 | 市场风向 | 强势板块 | 连板天梯 | 多板个股
                    ↓
各 Tab 对应独立 page 组件，共享顶部日期选择器（< 上一日 / 日期 >）
```

## 组件复用说明

- `StockLimitCard` + `SectorEmotionBar`：同时用于**强势板块页**（F13）和**涨停揭秘板块视图**（F4），两个入口共享同一套组件
- `StockRow`：通用股票行，复用于涨停伏击（F2）、多板个股（F15）、期货联动列表（F5）

## 数据请求规则

- 所有行情数据通过 `api/` 层调用 backend REST 接口，backend 从 PostgreSQL 读取（由 jobs/ 每日写入）
- 禁止在组件或 hooks 中直接调用 fetch / axios，必须通过 `api/` 层
- API 请求统一用 TanStack Query 管理缓存与状态
